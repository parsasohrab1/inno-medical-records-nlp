# inno-medical-records-nlp

**استخراج ساختار از پرونده‌ی فارسی**

> وضعیت: **TRL 4** — نمونه‌ی آزمایشگاهی با اعتبارسنجی اجزا روی **داده‌ی مصنوعی** (بدون داده‌ی بیمار). برای ارزیابی بالینی یا میدانی آماده نیست. ← [مستندات TRL](docs/TRL.md)

## نیاز شناسایی‌شده
ثبت ناقص و متنی پرونده‌ها و دشواری کدگذاری ICD-10.

## محصول
استخراج موجودیت‌ها و پیشنهاد کد ICD-10 از متن پزشکی فارسی.

## کاربران و ذی‌نفعان
مدارک پزشکی، کدگذاران، پژوهشگران

## قابلیت‌های هدف
- شناسایی بیماری، دارو و علائم
- پیشنهاد کد ICD-10
- بازبینی انسانی کدها

## داده
یادداشت‌های ترخیص و گزارش‌ها (بی‌نام‌شده). در مراحل اولیه فقط داده‌ی مصنوعی یا بی‌نام‌شده استفاده می‌شود.

## ریسک‌ها و محدودیت‌ها
کمبود پیکره‌ی فارسی پزشکی؛ حریم خصوصی.

## مسیر پیشنهادی
1. ✅ TRL 1 → 2: تعریف نیاز و معیار موفقیت (جدول معیارها در [docs/TRL.md](docs/TRL.md)).
2. ✅ TRL 3: نمونه‌ی آزمایشگاهی روی داده‌ی مصنوعی همراه با تست.
3. ✅ TRL 4: اعتبارسنجی اجزا در آزمایشگاه با تست‌های خودکار (CI روی هر push).
4. ⬜ TRL 5: اعتبارسنجی در محیط مرتبط با داده‌ی واقعی بی‌نام‌شده — نیازمندی‌ها در [docs/TRL.md](docs/TRL.md).

## یادداشت
این ریپو بخشی از مجموعه‌ی `inno-medical-*` برای دانشگاه‌های علوم پزشکی و وزارت بهداشت است. هیچ‌یک از خروجی‌ها جایگزین قضاوت بالینی نیست.

## راه‌اندازی سریع
```bash
pip install -r requirements.txt           # فقط numpy
export PYTHONPATH=src
python -m inno_medical_records_nlp generate --out data/sample # تولید داده‌ی مصنوعی (قطعی با seed)
python -m inno_medical_records_nlp validate                   # اجرای معیارهای TRL 4 روی ۳ seed
python -m inno_medical_records_nlp demo
python -m unittest discover -s tests -v
```

## آنچه پیاده‌سازی شده
نرمال‌سازی فارسی (ی/ک عربی، نیم‌فاصله، ارقام)، استخراج موجودیت با واژگان + تطبیق تقریبی (یک ویرایش)، نفی در محدوده‌ی جمله، پیشنهاد ICD-10 با پرچم بازبینی انسانی.
