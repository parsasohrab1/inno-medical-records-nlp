# کارت داده — inno-medical-records-nlp

- **منبع:** کاملاً مصنوعی؛ تولید با `python -m inno_medical_records_nlp generate --seed N` (قطعی). هیچ داده‌ی بیمار، شخص یا مرکز واقعی در ریپو نیست.
- **نمونه‌ی ذخیره‌شده:** `data/sample/*.csv` (seed=0).
- **فرض‌ها:** یادداشت‌ها از قالب‌های ساده با واژگان همان سیستم ساخته می‌شوند؛ بنابراین امتیاز بالا خوش‌بینانه است و روی متن آزاد واقعی افت خواهد کرد. واژگان فقط ۲۲ مدخل نمونه است.
- **استفاده‌ی مجاز:** توسعه و آزمون نرم‌افزار. استفاده برای آموزش/ارزیابی مدل بالینی یا هر تصمیم واقعی مجاز نیست.
- **حریم خصوصی:** هنگام ورود داده‌ی واقعی باید بی‌نام‌سازی، مجوز اخلاق و توافق‌نامه‌ی اشتراک داده انجام شود.
